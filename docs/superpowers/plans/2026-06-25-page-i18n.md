# Page I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add English/Simplified Chinese dropdown switching for the primary MobSF Web pages.

**Architecture:** Use Django native i18n with `LocaleMiddleware`, `set_language`, template translation tags, and compiled gettext catalogs. Limit this phase to page-visible Web UI strings, not API/log/report internals.

**Tech Stack:** Django templates, Django i18n, gettext `.po/.mo`, Docker Compose runtime.

---

### Task 1: Add Language Switching Tests

**Files:**
- Create: `mobsf/MobSF/tests.py`

- [ ] **Step 1: Write failing tests**

Add tests that call the login page, post to `set_language`, and assert English/Chinese page text.

- [ ] **Step 2: Run tests to verify they fail**

Run:

```bash
docker compose -f docker/docker-compose.yml exec -T mobsf python manage.py test mobsf.MobSF.tests.PageLanguageTests -v 2
```

Expected: failures because the route/template translation is not implemented yet.

### Task 2: Enable Django I18n

**Files:**
- Modify: `mobsf/MobSF/settings.py`
- Modify: `mobsf/MobSF/urls.py`

- [ ] **Step 1: Configure supported languages**

Add `LANGUAGES`, `LOCALE_PATHS`, and `LocaleMiddleware`.

- [ ] **Step 2: Add language switch route**

Wire `/i18n/setlang/` to Django's `set_language` view.

### Task 3: Translate Primary Templates

- [ ] **Step 3: Add language dropdown switcher**
